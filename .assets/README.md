# `.assets`

Two kinds of files live here:

| Kind | Path | Purpose |
|:-----|:-----|:--------|
| Screenshots | `*.JPG` | Evidence of the running url-shortener (Swagger, APIs, JUnit). Not agent instructions. |
| SOP / blueprint | `sop/spring-boot-agentic-sdlc/` | Playbook extracted from this repo for the **next** Spring Boot service. |
| How to use later | `HOW_TO_USE.md` | Copy/attach steps for this repo vs a new app. |

Cursor does **not** auto-load skills from `.assets`. The matching project skill is `.cursor/skills/spring-boot-agentic-sdlc/SKILL.md` (points at the SOP). Start with [HOW_TO_USE.md](HOW_TO_USE.md).
